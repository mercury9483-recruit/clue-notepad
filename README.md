# 클루 메모판

한국어판 클루 보드게임 메모판입니다. 칸을 누를 때마다 기록이 구글 스프레드시트에 한 줄씩 쌓입니다.

```
폰/PC 화면 (GitHub Pages) → Apps Script 웹앱 → 구글 스프레드시트
```

| 파일 | 역할 |
|---|---|
| `index.html` | 메모판 화면. 로그인 없이 열립니다. |
| `Code.gs` | 받은 기록을 시트에 쌓는 Apps Script |

## 시트에 쌓이는 내용

**Raw_기록** (칸을 한 번 누를 때마다 1줄)

| 시각 | 게임ID | 구분 | 카드 | 플레이어 | 표시 | 비고 | 이벤트ID |
|---|---|---|---|---|---|---|---|
| 2026-10-11 12:45:03 | G20261011-1245-k3x | 범인 | 머스타드 | 나 | ✗ | | … |

- 표시: `✓` 카드 가짐, `✗` 카드 없음, `?` 의심, `지움` 칸을 비움
- 카드 이름을 눌러 줄을 그으면 플레이어 칸은 비고 표시 칸에 `줄긋기` 또는 `줄긋기 해제`가 기록됩니다.
- 되돌리기로 바뀐 칸은 비고에 `되돌리기`가 붙습니다.

**Games** (게임 1판에 1줄): 게임ID, 시작시각, 인원, 플레이어, 최종수정

## 설치 순서

### 1. 스프레드시트와 Apps Script
1. 구글 스프레드시트를 새로 만듭니다. (이름 예: `클루 기록`)
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 위쪽 함수 선택에서 `setup`을 고르고 **실행**합니다. 처음 한 번 권한 허용 창이 뜨면 본인 계정으로 허용합니다. `Raw_기록`, `Games` 시트가 만들어집니다.

### 2. 웹앱 배포
1. **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
3. **배포**를 누르고 나오는 **웹 앱 URL**을 복사합니다. (`https://script.google.com/macros/s/…/exec`)
4. 그 주소를 브라우저에서 열어 `{"ok":true,...}`가 보이면 정상입니다.

### 3. 화면에 주소 넣기
`index.html` 위쪽의 `SHEET_URL = ''` 에 복사한 주소를 넣고 저장(커밋)합니다.

### 4. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**.
1~2분 뒤 `https://<사용자명>.github.io/clue-notepad/` 주소가 열립니다.

### 5. 확인
메모판에서 칸을 몇 번 누른 뒤 `Raw_기록` 시트에 줄이 생겼는지 봅니다. 화면 위 `게임 … · 시트 전송 완료` 문구가 보이면 전송까지 끝난 것입니다.

## 알아둘 점

- **전송 확인**: 브라우저 방식상 시트가 받았는지는 화면에서 확인할 수 없습니다. 전송 완료는 "보냈다"는 뜻이니, 실제 기록은 시트에서 확인하세요.
- **오프라인**: 전송에 실패하면 기록을 기기에 보관했다가 연결되면 다시 보냅니다. 같은 기록이 두 번 가도 시트에서 걸러냅니다.
- **보안**: 저장소와 웹앱이 모두 공개라서 주소를 아는 사람은 누구나 시트에 기록을 보낼 수 있습니다. `TOKEN`은 코드에 보이므로 완전한 보안은 아닙니다. 개인정보나 업무 자료는 이 방식으로 쌓지 마세요.
- **코드 수정 후 재배포**: `Code.gs`를 고치면 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해야 반영됩니다. 주소는 그대로 유지됩니다.
- **TOKEN 변경**: `index.html`과 `Code.gs`의 `TOKEN`을 같은 값으로 함께 바꿉니다.
